# Mining Macro (Fabric / Java版 1.21.1)

範囲を指定して高さ2マスで掘り進めるクライアントMod です。
水流・溶岩・穴を避け、鉱脈と指定アイテムを回収し、ツルハシの耐久が減ったら経験値瓶で自動修繕します。

> リポジトリ本体 (Commander-API) は統合版アドオンですが、このフォルダは独立した Java版 Fabric Mod です。

## 導入

1. Minecraft **1.21.1** + Fabric Loader + Fabric API を用意
2. このフォルダで `./gradlew build` → `build/libs/mining-macro-1.0.0.jar` を `mods` に入れる
   (GitHub Actions の `mining-macro build` の成果物 `mining-macro-jar` からも取得できます)

別バージョンで使う場合は `gradle.properties` の4つのバージョンを書き換えてください。

## 使い方

1. 範囲の角に立って `/mm pos1`、対角に立って `/mm pos2` (`/mm pos1 <x> <y> <z>` でも可)
   - **y は足元のブロックの高さ**。そこから上に2マス掘ります
2. 効率5のツルハシをメインハンドに持ち、範囲内か範囲の隣のマスに、範囲と同じ高さで立つ
3. `/mm start` または **F8** で開始。`/mm stop` または F8 で停止

チャットやインベントリを開いている間は自動で一時停止します。

### コマンド

| コマンド | 内容 |
| --- | --- |
| `/mm start` / `stop` / `status` / `reload` | 開始 / 停止 / 状態表示 / 設定ファイル再読み込み |
| `/mm pos1 [x y z]` / `/mm pos2 [x y z]` | 範囲の2点 |
| `/mm ore add <ブロックID>` / `remove` / `list` / `clear` / `default` | 回収する鉱石の指定 |
| `/mm ore look` | 今見ているブロックを鉱石に追加 |
| `/mm pickup nearest` | **一番近くに落ちているアイテム**を指定アイテムに登録 |
| `/mm pickup hand` | 手に持っているアイテムを登録 |
| `/mm pickup name <文字列>` | 表示名にその文字列を含むアイテムを登録 |
| `/mm pickup add <アイテムID>` | アイテムIDで登録 |
| `/mm pickup list` / `remove <番号>` / `clear` | 一覧 / 削除 |
| `/mm pickup all <true\|false>` | 落ちているアイテムを種類を問わず全部拾うか (初期値 true) |

### サーバー独自アイテムについて

ID も見た目も分からないアイテムへの対策を2段構えにしています。

- **`pickup all` (初期値 true)** — 種類を問わず、範囲内に落ちたアイテムは全部拾いに行きます。事前登録なしでも独自アイテムを取り逃しません。
- **指定アイテム** — 一度でも現物を見たら `/mm pickup nearest` (落ちている状態) か `/mm pickup hand` (拾った後) で登録してください。アイテムID・CustomModelData・カスタム名の組で記憶します。
  指定アイテムは最優先で拾いに行き、`itemTimeoutTicks` (初期値 400tick = 20秒) 以内に拾えなければ**緊急停止して座標をチャットに出します**。

## 安全対策

| 状況 | 動作 |
| --- | --- |
| 壊すブロックの上下左右前後に水・溶岩がある | そのブロックは壊さない (上に砂利などが積まれていれば、その山の上まで確認) |
| 床が無い・床が液体やマグマ | そのマスには入らず、迂回経路を計算 |
| 隣のマスに穴や液体がある | スニークで歩く (縁から落ちない) |
| 水・溶岩に触れた / 高さが変わった / ダメージを受けた | 緊急停止 |
| 進めなくなった | 経路を引き直し、3回続いたら緊急停止 |
| 床下の鉱石 | 掘ると穴になるので掘らず、完了時に座標を報告 |

回避したマスの数は HUD と完了メッセージに出ます。

## 修繕 (経験値瓶)

残り耐久が `repairThreshold` (初期値 **100**) 以下になった時点で、次の手順を行います。

1. `/mib` を実行
2. 開いたメニューのディスペンサーをクリック
3. 表示された経験値瓶を shift+右クリックで 64×2 取り出す
4. メニューを閉じ、ツルハシをオフハンドに持ち替える
5. メインハンドで瓶を足元に投げ、持っている瓶を使い切る
6. ツルハシをメインハンドに戻し、**耐久が増えて閾値を上回ったか確認**

次の場合は緊急停止します。

- メニューが開かない / ディスペンサーや瓶が見つからない / 瓶を取り出せない
- 持ち替えに失敗した
- 修繕後の耐久が、修繕前から増えていない、または閾値以下のまま
- (常時) 残り耐久が `hardStopDurability` (初期値 30) 以下、またはメインハンドがツルハシでない

ツルハシを壊すと失格になるため、閾値 100 → 強制停止 30 の二重の安全域を取っています。

## 動きの自然さ

- 視点は瞬間移動させず、毎 tick 速度上限・減速・ゆらぎつきで目標へ寄せます。回転量はマウス感度の最小単位に丸めています
- ブロックは中心ではなく、見えている面のランダムな点を狙います
- 実際に視線が当たっているブロックだけを掘ります (壁越しの採掘はしない)
- 移動は前進キー・スニークキーの入力として行います
- ブロックを壊した後や修繕の各手順に、ランダムな間を入れています

## 設定ファイル

`config/miningmacro.json` (初回起動時に生成)。コマンドで変えられない項目:

| キー | 初期値 | 内容 |
| --- | --- | --- |
| `height` | 2 | 掘る高さ |
| `oreUp` | 3 | 天井より上、何マスまで鉱脈を追うか |
| `repairThreshold` | 100 | 修繕を始める残り耐久 |
| `hardStopDurability` | 30 | 強制停止する残り耐久 |
| `bottleCommand` | `mib` | 瓶メニューのコマンド |
| `menuButtonItem` | `minecraft:dispenser` | メニューでクリックするアイテム |
| `bottleStacks` | 2 | 取り出すスタック数 |
| `itemTimeoutTicks` | 400 | 指定アイテム回収の制限時間 |
| `rotationSpeed` | 1.0 | 視点移動の速さ倍率 |
| `maxActionDelay` | 4 | 破壊後の待ち時間の上限 (tick) |

## 制限

- 鉱脈は「立っている位置から見えて手が届く」範囲で回収します。届かない奥の鉱石は完了時に報告します
- 範囲外へは歩いて出ません (範囲の外周1マスの、既に空いているマスのみ通行可)
- 段差のある地形には対応していません (全域が同じ床の高さである前提)
